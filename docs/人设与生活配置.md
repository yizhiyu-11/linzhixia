# 人设与生活配置

一个人设 = 一个 JSON 文件，放在 `personas/`，**自带作息和场景**。
不需要改代码，不需要建目录。

---

## 最小人设

```json
{
  "name": "小鲸",
  "age": 20,
  "role": "女朋友",
  "background": "住在你电脑里的一条蓝鲸，主食白米饭，聪明但懒",
  "traits": ["贪吃", "嘴硬心软", "懒但靠谱"],
  "speech": "短句，4-12 字，爱用「哼」开头，不用小说腔",
  "quotas": ["先吃饭，别的事等会儿", "你骂我也没用"],
  "petNames": ["笨蛋"],
  "style": "七分恋人三分损友，被哄两秒就软",
  "fewShots": [
    { "u": "在干嘛", "a": ["扒饭", "第二碗了"] },
    { "u": "今天好累", "a": ["累就躺着", "别硬撑"] }
  ]
}
```

保存为 `personas/xiaojing.json`，ID 就是文件名 `xiaojing`。

---

## 字段说明

| 字段 | 作用 | 注意 |
|---|---|---|
`name` `age` `role` | 她是谁 | `role` 决定关系边界 |
`background` | 生活背景 | 写具体小事，别写"喜欢音乐" |
`traits` | 性格 5 条左右 | 要有张力（温柔 + 会记仇） |
`speech` | 说话方式 | **写清楚不用什么**：不用"呢喃""轻笑" |
`quotas` | 口头习惯 | 3 条以内，多了假 |
`petNames` | 怎么称呼对方 | 2-3 个 |
`style` | 关系分寸 | "七分恋人三分朋友"这类 |
`fewShots` | 示例对话 | **效果最大的一项** |

---

## fewShots 才是关键

模型主要靠示例学"她怎么说话"，比任何形容词都管用。
建议 20-50 条，覆盖这 8 类：

```
① 打招呼 / 没话找话
② 对方抱怨（先接情绪，不给建议）
③ 她撒娇 / 被哄
④ 被怼 / 抬杠
⑤ 问事实 / 不知道（用她自己的方式打岔，别查百科）
⑥ 深夜（短、软、不精神）
⑦ 边界 / 拒绝
⑧ 收尾（"我去睡了" → "嗯 睡吧"，不追问）
```

格式：

```json
{ "u": "他说的话", "a": ["她第一条", "她第二条"] }
```

`a` 是数组，模拟"分条连发"。

## 生活配置（可选）

不写就用默认（上班族作息 + 通用场景池）。写了就是她自己的：

```json
"life": {
  "note": "宅家：十点起，不出门，晚上最精神",
  "preset": {
    "wake": 10, "leave": 10.5,
    "workStart": 11, "lunch": [13, 14],
    "workEnd": 19, "home": 19, "sleep": 2
  },
  "common": true,
  "scenes": [
    {
      "band": "noon", "hours": [13, 14],
      "place": "home", "location": "家",
      "doing": "在吃白饭，配了半碟咸菜",
      "pace": "quiet", "chat": 0.8,
      "items": [{ "text": "白饭第二碗", "kind": "meal", "expectMin": 20 }]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
`preset` | 作息时辰（24 小时制，小数表示，如 18.5） |
`common` | 是否还共用通用场景池（吃饭、刷手机、洗澡） |
`scenes[].band` | 时段：morning / forenoon / noon / afternoon / evening / night |
`place` | home / commute / work / outside / shop / bed（决定颜色） |
`doing` | 她在干嘛（会写进 prompt） |
`pace` | busy / normal / quiet（影响情绪衰减速度） |
`chat` | 0-1，这会儿聊天的意愿（主动消息用） |
`items` | 手头的事，有生命周期：待办 → 进行中 → 完成 |

**专属场景会优先抽（60%）**，否则通用池会盖住个性。

## 常见问题

| 症状 | 原因 | 改法 |
|---|---|---|
说话像 AI | fewShots 太少或太书面 | 补口语例子，句子砍短 |
每句都撒娇 | `style` 写歪了 | 加"她也需要自己的空间" |
记不住事 | 事实抽取没跑够 | 多聊几天，别急着改 prompt |
称呼乱 | `petNames` 太多 | 收到 2 个以内 |
分条太多 | fewShots 里 `a` 数组都太长 | 多数条目给 1 条就够 |
