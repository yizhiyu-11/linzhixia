# 情绪是什么：文献综述与设计结论

> 目的：在动手写代码前，先弄清心理学和计算模型里"情绪"到底是什么、能怎么算。
> 结论在第七节——它会改掉我们上一版模型的两个关键假设。

---

## 一、四种主流框架

### 1.1 基本情绪论（Ekman）

情绪是有限几个**离散类别**（愤怒、厌恶、恐惧、快乐、悲伤、惊讶），跨文化可识别，有对应的面部表情和生理模式。

**对我们的价值**：标签好懂，用户能理解"她生气了"。
**问题**：类别之间不连续，没法做数值叠加和衰减；而且文化差异被后续研究反复质疑。

### 1.2 维度论（Russell 环状模型、Mehrabian PAD）

情绪不是离散的，而是落在连续空间里：

```
Russell（1980）：valence（愉悦）× arousal（唤醒）二维环状
Mehrabian：再加 dominance（掌控感），成 PAD 三维
```

**对我们的价值**：能算、能衰减、能叠加——这正是我们需要的形式。
**问题**：只说"有多愉快、多激动"，不解释"为什么"。

### 1.3 评价论（Scherer 的 Component Process Model）

情绪由**对事件的评价**产生，评价分几个检查点：

```
相关性   这事跟我有关吗
含义     对我好还是坏、重要吗
应对     我能不能应付
规范     符不符合我的标准
自我     和我对自己的看法一致吗
```

评价结果同时改变五个成分：主观感受、生理、表情、行为倾向、认知。

**对我们的价值**：**这是"被老板说了 → 生气"的机制解释**。同一个事件，评价不同，情绪不同（被路人说 vs 被老板说）。
**问题**：评价维度多，实现要简化。

### 1.4 建构论（Barrett）

情绪不是被触发的固定程序，而是大脑对**内感受（身体状态）+ 概念知识**的实时构造。同一套身体信号，在不同情境下被归类成"生气"或"饿"。

**对我们的价值**：解释了为什么"身体状态"（睡眠、饥饿）会改变情绪；也支持"标签是解释，不是本体"。
**问题**：难以直接工程化，但它的两个副产品很有用——**核心情感（core affect）** 和 **情绪粒度**。

## 二、三层：情绪 / 心情 / 性格

计算模型里最成熟的划分是 ALMA（Gebhard）：

| 层 | 时间尺度 | 例子 | 变化速度 |
|---|---|---|---|
情绪 emotion | 秒~分钟~小时 | 被老板说了，当下火大 | 快 |
心情 mood | 小时~天 | 今天整体不顺 | 慢 |
性格 personality | 长期 | 她本来就偏温和 | 几乎不变 |

**这一层区分很重要**：我们上一版模型只做了"情绪"一层，缺了 mood——所以没法表达"今天一整天都不太对劲"。

---

## 三、实证：情绪能持续多久

Verduyn & Lavrijsen（2014，*Motivation and Emotion*）让 233 名被试回忆最近一次情绪，报告持续时长，覆盖 27 种情绪：

| 情绪 | 平均持续 |
|---|---|
悲伤 | **5 天**（约 120 小时） |
憎恨 | 60 小时 |
喜悦 | 35 小时 |
恐惧 | 约 40 分钟 |
羞愧 | 约 40 分钟 |
厌恶 | 约 30 分钟 |

### 关键结论（这条最重要）

> **决定时长的不是情绪类别，而是事件的重要性和后果。**

悲伤长，是因为它通常关联重大失去、且引发反刍（rumination）；厌恶短，是因为它指向具体刺激，避开就结束了。

对我们的含义：

```
❌ 错误做法：给"生气"设一个固定半衰期
✅ 正确做法：半衰期由"事件重要性 × 后果持续 × 是否反刍"决定
```

## 四、动力学：情绪有惯性

Kuppens 等人的"情绪惯性"（emotional inertia）研究发现：

```
前一刻的情绪状态，强烈预测下一刻
惯性越高，心理适应越差（抑郁、低自尊者惯性更高）
```

对我们的含义：

```
· 情绪不能每轮翻转（现在"mood"每轮读一次其实还好，但情绪层必须连续）
· 应该有"余温"：上一轮的负面情绪会让这一轮略负面
· 但惯性过高会"卡住"——需要上限
```

---

## 五、调节：人不是被动等情绪消退

Gross 的过程模型把情绪调节分成五个时点：

```
① 情境选择   避开会让自己难受的场合
② 情境修正   改变环境（换个位置、关掉手机）
③ 注意分配   转移注意力（刷视频、找人说话）
④ 认知改变   重新解读（"他不是针对我"）
⑤ 反应调整   压住不表现（表面平静）
```

**对我们的价值**：她可以**自己调节**，而不是干等衰减：

```
生气 → 去做点别的事（场景切换）→ 衰减加速
难过 → 找人说话（如果他在，就主动找他）
```

这也是"她情绪会影响后面发生的事"的另一种实现。

## 六、计算模型能借什么

| 模型 | 核心 | 我们能用的部分 |
|---|---|---|
OCC（Ortony 等） | 事件/行为/对象 → 22 种情绪类型 | **评价结构**：事件→后果评价 |
PAD（Mehrabian） | 三维连续空间 | **数值表达**：可衰减、可叠加 |
ALMA（Gebhard） | 情绪/心情/性格三层 + mood 衰减 | **分层**：快慢两种时间尺度 |
FAtiMA | 评价 + 应对 + 关系 | **关系状态影响情绪强度** |

## 七、对我们上一版模型的修正

### 修正 1：加"心情"层（mood）

```
emotion：由事件注入，半衰期分钟~小时
mood：由情绪长期平均漂移，半衰期 6-24 小时
```

表现差异：

```
emotion = 生气 0.7，mood 正常 → 她这一句带刺，但整体还正常
emotion = 生气 0.4，mood 偏低 → 她"最近一直不太高兴"，说话整体偏冷
```

### 修正 2：半衰期动态化，不按标签固定

| 事件类型 | 半衰期 | 依据 |
|---|---|---|
小确幸（午饭好吃） | 30-60 分钟 | 厌恶/喜悦类短 |
日常摩擦（地铁被挤） | 1-2 小时 | 低重要性 |
工作受挫（被说） | 6-12 小时 | 中等重要性 + 后果 |
关系伤害（被冷落、被否定） | 1-3 天 | 高重要性 + 反刍 |
重大失去 | 数天 | Verduyn 数据（悲伤 5 天） |

### 修正 3：加"反刍"机制

```
如果这件事反复进入思考（她一个人待着、没别的事做）→ 衰减变慢（×0.5）
如果她有别的事在忙（场景有 pending）→ 衰减正常或加快
```

**这是"悲伤能持续 5 天"的工程解释**：不是悲伤本身长，是她一直在想。

### 修正 4：加"调节"机制

```
场景有 pending（她有事做）→ 注意力被占 → 衰减加快（×1.3）
她在找他说话/他来安慰    → 衰减加快（×1.5，最多提前 60%）
```

### 修正 5：情绪由评价产生，不是由事件直接产生

```
事件：被老板说了
评价：他当着同事说 → 丢脸（自我评价受损）→ 羞耻 + 生气
同一事件，如果是"他私下提醒我" → 评价不同 → 只是有点懊恼
```

所以场景事项应该带 **appraisal 标签**（丢脸 / 被否定 / 被需要 / 被忽视），而不只是 `moodImpact` 数值。

## 八、修正后的数据结构

```js
// 场景事项（带评价，不带情绪）
{
  text: '被叫去办公室',
  kind: 'work',
  appraisal: { relevance: 0.8, goalCongruence: -0.7, agency: 'other', selfImage: -0.5 },
  // → 由评价层换算成情绪注入
}

// 情绪层输出
{
  emotion: { v: -0.5, a: 0.6, e: -0.15, label: '羞恼', halfLifeMin: 480, cause: '被老板当众说' },
  mood:    { v: -0.2, a: 0.45, decayHalfLifeMin: 720 },
  inertia: 0.35   // 上一轮情绪的影响权重
}
```

---

## 九、设计结论（一句话版）

```
情绪 = 对事件的评价 × 重要性 → 注入到 PAD 空间 → 按动态半衰期衰减（受反刍/调节影响）
心情 = 情绪的慢速滑动平均
标签 = 给人看的，不参与计算
```
