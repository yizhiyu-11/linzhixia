# 用户情绪模型（UAffect）实现与验证

> 时间：2026-10-30　范围：`src/uaffect.mjs` + 接入 `index.mjs` / `proactive.mjs`
> 依据：`docs/技术/情绪模型设计.md` §12（她对"他"的判断）

---

## 一、它解决什么

感知层每轮独立判断：翻转率实测 35.4%，只有类别没有强度，判不准就不判（难过/生气 0%）。
所以再加一层，把零散的句子级判断 + 行为信号，滑成**一个人的状态**。

只给下游三个数：

| 输出 | 含义 | 谁用 |
|---|---|---|
| `empathy` | 该共情到什么程度 | 生成层（提示词） |
| `caution` | 收敛程度：别开玩笑、别贫 | 生成层（提示词） |
| `allowProactive` | 现在能不能主动找他 | 主动消息门槛 |

置信度 < 0.4 时**三个数一律不做动作**——宁可当没看出来，也不瞎共情。

---

## 二、状态与更新

```js
UAffect = { v, a, confidence, trend, updatedAt, meta }
meta = { shortRun, negRun, n }   // 连续短回复、连续负面、累计轮数
```

每轮（`updateUAffect`）：

```
① 语气（感知层 tone{label,intensity}）→ (v,a) 先验，权重 = intensity × 0.6，加权滑动
② 行为信号：
   连续 <5 字的回复 → v 向 -0.5 拉（第 2 条起，最多 0.45）
   距上条 >30 分钟   → confidence -0.12（更难判断）
   距上条 >180 分钟  → v 向 0 拉 0.25（当时的情绪已经淡了）
③ 安全网：
   全新用户 confidence 从 0.15 起；超过 12 小时没说话重置到 0.3 并衰减旧值
④ 收尾：trend = 0.5×旧 + 0.5×本轮变化；连续负面计数（v ≤ -0.2）
```

判据：

```
blind   = confidence < 0.4
risk    = 连续 3 轮负面 且（连续短回复 ≥2 或 trend < -0.02）
empathy = -v × 2 × min(1, confidence / 0.6)
caution = -v × 1.4 + max(0, a - 0.55) × 0.9 + risk×0.2
allowProactive = 否 当 risk / v ≤ -0.4 /（v ≤ -0.25 且 confidence ≥ 0.5）
```

## 七、回放结果：预测这一层没通过验证（2026-10-30）

脚本：`scripts/uaffect-replay.mjs`（只读，可复跑）。
数据：`data/bot.db`，2 个真实用户、177 条感知、445 条消息；可用样本 70 条。
弱标签：变短 = 下一条比这条短 40% 以上且这条 ≥6 字；不聊 = 120 分钟内没下一条。

| 指标 | 结果 | 判读 |
|---|---|---|
| v 分布 | 最小 -0.28 · 中位 **+0.10** · 最大 0.47 | 几乎是常数 |
| 变短基线 | 47.1%（33/70） | 接近抛硬币 |
| 不聊基线 | 3.4%（6/177） | 标签几乎不出现，没法用 |
| AUC（-v → 变短） | **0.360** | 反了，还不如随机 |
| AUC（-trend → 变短） | 0.495 | 无信号 |
| AUC（-v → 不聊） | 0.352 | 无信号 |
| 规则 v≤-0.25 准确率 | 52.9%，等于多数类 52.9% | 等于全猜 |
| 个人基线（长度比/间隔比） | AUC 0.22~0.54 | 还是无信号 |

**为什么 v 不动**：真实情绪分布是 平静 59% / 撒娇 25% / 开心 15% / 焦虑 1% / 生气 1%。
负向只占 2%，而 v 的负值只由负向语气拉动，所以它长期停在 +0.05~+0.15。
推论：`empathy` 长期为 0、`allowProactive` 几乎不会变 false——这套现在**几乎不会动作**。

**为什么标签也不行**：变短在 47% 上下，本身就是个噪声标签；不聊只有 3.4%。
两个用户、177 轮，任何比例都撑不起结论。

**合成语料（`data/_run.db`，57 条带 tone）里 AUC 0.742**：只能说明"负向语气出现时机制是通的"，
不能当证据——那是脚本造的对话，标签也是造的。真实数据里负向语气根本不出现。

### 结论

1. **不要按"预测"上线**。设计 §12.4 的短期预测在当前数据上不成立。
2. 现在的 UAffect 可以当**稀有事件识别**用（他真的生气/焦虑时收敛、共情），
   这比"预测"窄，但不会出错，也不该再为它调参。
3. 想验证预测，得先有足够负向样本：要么等几周真实数据，要么人工标注情绪——
   在 2 个用户、177 轮上继续调权重，只是在拟合噪声。
