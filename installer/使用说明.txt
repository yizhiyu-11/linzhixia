林知夏 · AI 角色对话系统（本地版 v1.0）
================================================
详细版见 操作说明.html（双击「打开说明书.cmd」），
里面有安装、QQ 接入、故障排查、备份、卸载全套步骤。
================================================

一、这是什么
------------
一个装在自己电脑上的 AI 角色对话程序，通过 QQ 和你聊天。
她会记住你说过的事，有自己的说话方式，所有聊天记录都存在你自己电脑里。

二、安装前先准备两样东西
------------------------
1. 模型 API Key（必须有）
   platform.deepseek.com 注册 → 充值 → 「API Keys」创建 → 复制 sk- 开头的字符串。

2. QQ 连接中间件（想接 QQ 才需要）
   需要你在自己电脑上运行一个 OneBot 服务（例如 NapCat、SnowLuma 这类工具），
   让它在 127.0.0.1:3001 提供 WebSocket 接口，并用你的机器人 QQ 登录。

   【重要】本安装包不包含这类工具，也不代安装。原因有两个：
   · 它们按 QQ 版本适配，打包会固定在某个版本，腾虎升级后连不上；
   · 这类工具属于第三方非官方实现，可能违反平台用户协议，账号风险由你判断。

   不装也能用：双击桌面「打开聊天」，在浏览器里和她聊。

三、怎么装
----------
1. 把整个文件夹放到你不会删的位置（比如 D:\林知夏）
   —— 不要放桌面或临时目录，会被清理
2. 双击「一键安装.cmd」，会打开一个安装向导
3. 按向导走五步：
   ① 欢迎（自动检查你的环境：QQ 版本、中间件、端口）
   ② 填模型 API Key（可以跳过）
   ③ 填 QQ 连接信息（可以跳过，右侧有「测试连接」）
   ④ 安装（写配置、建桌面图标、启动服务）
   ⑤ 完成（提示关掉 QQ 自动更新）
4. 装完桌面会有四个图标

四、关于 QQ 版本（请认真看）
---------------------------
这类中间件是按 QQ 版本适配的，版本对不上会连不上。参考经验：

   QQ 9.9.22 ~ 9.9.23    配 NapCat 4.18.x 可用（旧组合）
   QQ 9.9.30 以上（如 9.9.36）  NapCat 4.18.41 注入会失败，需要用 SnowLuma 这类新版

装完后请务必做一件事：**关掉 QQ 的自动更新**
   QQ → 左下角菜单 → 设置 → 关于 / 更新 → 选「不自动更新」
原因：自动升级会让原本能用的中间件突然失效。

【换 QQ 版本有风险，动手前先备份】
· 我们程序自己的记忆库（app\data\bot.db）不受影响，跟 QQ 版本无关
· 你的 QQ 本地聊天记录：NT 版会做数据库升级，升级后不保证能降级回旧版，
  降级有可能读不到旧数据。**换版本前，先把下面这个目录整个复制一份**：
      C:\Users\你的用户名\Documents\Tencent Files
· 换版本或换安装路径，可能要求重新扫码登录（属正常现象）
· 建议：除非中间件明确要求，否则不要主动改 QQ 版本

五、装完怎么用
--------------
  启动林知夏        启动程序（装完会自动启动一次）
  林知夏 管理后台    改人设、调参数、看用量、改 Key
  林知夏 测试连接    检查 QQ 有没有连上
  停止林知夏        关闭程序

用 QQ 给机器人号发消息，她就会回你。

六、费用
--------
一轮对话约 0.005 元。每天聊 100 轮，一个月约 15 元，从模型平台余额扣。

七、能改什么
------------
管理后台里可以改：人设、回复节奏、记忆、主动消息、模型、语音、安全边界。

八、数据在哪
------------
全部在 app\data\ 目录：
  bot.db        聊天记录与记忆（重要，别删）
  web-token     后台访问令牌
备份：把 data 整个文件夹复制走即可。

九、出问题怎么办
----------------
【QQ 不回复】
1. 双击「林知夏 测试连接」看报什么错
2. 连不上 → 中间件没启动，或地址/端口不对
3. 401 → Token 与中间件配置不一致
4. 能连但不回 → 你的 QQ 号没进白名单
   打开「林知夏 管理后台」→ 访问权限 → 补上

【中间件突然不能用】
· 大概率是 QQ 自动更新了版本 → 看第四节，换匹配的中间件版本
· 改完版本记得重新备份 Tencent Files

【她回复慢或报错】
· 多半是 API Key 没填或余额不足 → 后台「模型」页看状态

【打不开】
· 双击「停止林知夏」，再双击「启动林知夏」

【端口被占用】
· 安装时自动换端口；手动改在 app\.env 的 WEB_PORT

【想看日志】
· app\logs\ 目录

十、卸载
--------
1. 双击目录里的「卸载.cmd」
2. 勾选「保留聊天记录」（默认勾着，会备份到桌面）→ 点「卸载」
3. 等它提示完成

不勾选「保留」= 连聊天记录一起删，删了找不回来。
卸载只删程序本身和桌面图标，不动你的 QQ 和系统设置。
