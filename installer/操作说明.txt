开始前必看（30 秒）

【严重】三件事不做，后面全是麻烦
① 关掉 QQ 自动更新 —— 不关的话，腾讯一升级，中间件立刻失效，你会以为程序坏了。
② 改 QQ 版本之前，先备份 Tencent Files —— QQ NT 数据库升级后不保证能降回去。
③ 每个月复制一次 app\data —— 里面有她的记忆，程序可以重装，记忆重装不回来。

【重要】用什么号
建议专门注册一个机器人号，不要拿主号试。第三方接入有平台风险，这条不是危言耸听。

【提示】只想先试试？
不接 QQ 也能用：装完双击「打开聊天」，在浏览器里和她聊。QQ 那部分随时可以补。



零基础操作指南

这一节给"完全没折腾过软件"的人。已经会解压、会装软件的可以跳过。

① 怎么解压

收到的是一个 .zip 压缩包：

- Win11：右键压缩包 →「全部解压缩」→ 选择位置 → 解压
- Win10：右键 →「提取全部」→ 选择位置 → 提取
- 没有这两个选项？双击压缩包，资源管理器里点上方「解压 / 提取」

解压后应该看到一个文件夹，里面有 一键安装.cmd。不要直接在压缩包里双击运行，会报错。

② 放到哪

好：D:\林知夏          （盘符根目录 + 简单名字）
好：D:\软件\林知夏     （中文可以，别太长）
别：桌面              （会被清理工具删）
别：下载文件夹         （会被定期清空）
别：很深的嵌套路径      （路径总长超过 260 字符会出问题）

③ 我的 QQ 号在哪看

- 电脑 QQ：点左下角头像 → 昵称下面就是 QQ 号；或「设置」→「账号管理」
- 手机 QQ：左上角头像 → 点自己的名字 → 看「QQ 号」

填写的格式就是纯数字，例如 123456789。

④ "机器人号"是什么，怎么来

指专门用来跑程序的那个 QQ 号。

- 可以是你自己的小号
- 也可以新注册一个（手机 QQ 登录页 →「新用户注册」）
- 不建议用主号，原因见第 12 章

注册好之后，在手机 QQ 里登录一次（过一下验证），再在电脑 QQ 里登录，方便扫码。

⑤ 提示"Windows 已保护你的电脑"

这是 SmartScreen 对没有数字签名的程序的标准提示，不是病毒：

点「更多信息」→ 点「仍要运行」

⑥ 杀毒软件报毒 / 把文件删了

内置的运行环境（runtime\node.exe）和脚本可能被杀软误判。处理：

1. 打开杀软 →「信任区 / 白名单 / 排除项」
2. 把整个安装文件夹加进去
3. 如果文件已经被隔离，先从隔离区恢复，再加白名单

Windows 自带的 Defender：设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 →「管理设置」→ 添加排除项。

⑦ 我是不是 64 位系统

右键「此电脑」→ 属性 → 看「系统类型」：

64 位操作系统  →  可以用
32 位操作系统  →  不支持（程序里的运行时是 64 位的）



1. 这是什么

一个装在你电脑上的 AI 角色对话程序。它会记住你说过的事，有自己的说话方式，通过 QQ 和你聊天。

它能做的：

- 记住聊天内容（长期记忆 + 每天/每周总结）
- 有固定的性格和说话习惯，不是客服腔
- 会主动找你（可选，默认开）
- 管理后台里可以改人设、回复节奏、记忆规则、模型
- 所有聊天记录存在你自己电脑上

它不做的：

- 不提供 QQ 账号，也不代登录
- 不包含 QQ 中间件（NapCat / SnowLuma 那类工具），需要你自己装
- 不承诺账号安全（第三方接入有平台风险，见第 12 章）
- 不带模型额度，API 费用自理



2. 系统要求

  项目   要求   说明  
 --- --- --- 
  系统   Windows 10 1809+ 或 Windows 11，64 位   不支持 Win7/8、macOS、Linux  
  内存   4 GB 以上   8 GB 更稳  
  磁盘   至少 1 GB 空闲   程序本身约 120 MB，聊天数据会慢慢长大  
  网络   能访问模型 API   国内可直连 DeepSeek  
  权限   普通用户权限即可   不写系统目录、不装驱动、不改注册表  
  运行环境   无需安装   Node.js 已内置在包里  

安装位置建议：D:\林知夏 这类固定目录。不要放在桌面、下载文件夹、临时目录——会被清理或误删。



3. 安装前准备

3.1 申请模型 API Key（必做）

1. 打开 platform.deepseek.com，注册并登录
2. 充值（首次 10 元够聊很久）
3. 左侧「API Keys」→「创建 API Key」
4. 复制以 sk- 开头的字符串，只显示一次，先存到记事本

费用参考见第 11 章。

用别的模型服务也行：后台「模型」页可以改 Base URL 和模型名。但本说明以 DeepSeek 为例。

3.2 决定要不要接 QQ

两种用法，任选：

  用法   需要什么   适合谁  
 --- --- --- 
  A. 浏览器里聊   只要安装包 + API Key   想先试试、不想折腾  
  B. 在 QQ 里聊   额外装一个中间件（NapCat 或 SnowLuma）+ 一个机器人 QQ 号   想随时在手机上聊  

先装 A 也能用，之后随时补 B。

3.3 准备中间件（只有选 B 才需要）

  中间件   适配的 QQ 版本   获取方式  
 --- --- --- 
  NapCat 4.18.x   QQ 9.9.20 ~ 9.9.29   GitHub NapNeko/NapCatQQ 的 Releases  
  SnowLuma 2.2.x   QQ 9.9.30 以上（含 9.9.36）   GitHub SnowLuma/SnowLuma 的 Releases  

【严重】这部分有风险，你要自己判断
这两个都是第三方非官方实现，可能违反平台用户协议，可能导致账号被限制。
本安装包不附带、不代装。账号风险由你自行承担，程序不承诺任何账号安全。

装机顺序很重要：先确认 QQ 版本 → 再选匹配的中间件 → 最后装本程序。



4. 安装

4.1 开始

1. 把整个文件夹解压到固定位置（如 D:\林知夏）
2. 双击 一键安装.cmd
3. 出现安装向导窗口（五步）

如果 Windows 弹「未知发布者」，点「更多信息」→「仍要运行」。原因：程序没有买代码签名证书，不是病毒。

4.2 第 1 步：欢迎 / 环境自检

向导会自动检查并显示：

· QQ：已安装，版本 9.9.23.42430（D:\qq）
· QQ 连接中间件：未检测到 OneBot 服务（可选，不装也能用浏览器聊）
· 连接诊断：发现工具目录，但 3001 没监听 —— 多半是注入失败或没登录
· 内置运行环境：已打包，无需另外安装 Node.js
· 管理后台端口：3870

怎么读这段：

  显示   含义   要不要处理  
 --- --- --- 
  QQ 已安装 + 版本   检测到 QQ 了   记下版本，第 6 章要用  
  未检测到 OneBot 服务   中间件没跑   只想浏览器聊就无视；要接 QQ 就看 6.3/6.4  
  连接诊断「没监听」+ 有工具目录   工具装了但没起来   看工具窗口报错，多半版本不匹配  
  管理后台端口 3870   后台地址是 http://127.0.0.1:3870   被占用会自动换 3871~3885  

4.3 第 2 步：填 API Key

粘贴第 3.1 拿到的 sk-...。

- 可以先跳过，装完在后台「模型」页填
- 填错也能改，不影响安装

4.4 第 3 步：QQ 连接（可跳过）

三个输入框：

  字段   填什么   默认  
 --- --- --- 
  OneBot 地址   中间件提供的 WebSocket 地址   ws://127.0.0.1:3001  
  Token   中间件里设的 token，没设就留空   空  
  谁可以和她聊天   你的 QQ 号，多个用英文逗号；第一个当"主人"   空  

填完点 「测试连接」：

连接成功：昵称（QQ号）     → 可以下一步
连不上：没有程序在监听这个端口 → 中间件没启动
连接被拒（401）           → token 不一致

连不上就点 「一键修复」（见 6.6），或者先跳过——浏览器聊天不受影响。

4.5 第 4 步：安装

自动做四件事，进度会打印出来：

1. 写配置（app\.env）
2. 建桌面快捷方式（4 个）
3. 启动服务
4. 检查 QQ 连接

4.6 第 5 步：完成

- 成功：会打开管理后台页面
- 未连上 QQ：会列出三条检查项，不影响基础使用

装完请务必做一件事：关掉 QQ 自动更新（见 6.5）。



5. 首次启动与验证

5.1 桌面四个图标

  图标   作用  
 --- --- 
  启动林知夏   启动程序（装完已经自动启动过）  
  林知夏 管理后台   打开后台：人设、参数、记忆、用量  
  林知夏 自检   四项状态一眼看清（程序 / QQ / 白名单 / Key），装完先看这个  
  林知夏 测试连接   只检查 QQ 连接细节  
  停止林知夏   关闭程序  

5.2 先看自检（最重要）

双击桌面「林知夏 自检」，会出现一个窗口，四行状态：

① 程序在运行      运行中（端口 3870）
② QQ 已连接       已连接 / 机器人号
③ 白名单          1 个号 / 你的 QQ
④ 模型 Key        已填（sk-…）

全绿 = 能用了。哪行红了，下面那行小字就写着怎么修，窗口底部还有对应按钮：

重新检查 · 启动程序 · 修复 QQ 连接 · 打开管理后台 · 打开聊天

最常见的一种红：④ 模型 Key 没填（安装时跳过了）→ 点「打开管理后台」→ 模型 → 填 Key → 回来点「重新检查」。

5.3 验证三件事

① 后台能不能打开

浏览器访问 http://127.0.0.1:3870（端口以安装时显示为准）。能看到登录页说明服务正常。

② 浏览器里能不能聊

双击「打开聊天」，随便发一句，几秒内有回复就通了（说明 API Key 正确、网络正常）。

③ QQ 里能不能收到回复

双击「测试连接」：

连接成功：XXX（123456789）   → QQ 已就绪

然后在 QQ 里给机器人号发消息。5~10 秒没回，看第 9 章。



6. 接入 QQ（重点）

6.1 原理一句话

你的 QQ ←→ 中间件（NapCat / SnowLuma）←→ 本程序（通过 ws://127.0.0.1:3001）

中间件负责登录 QQ、收发消息；本程序负责生成回复。中间件不在，本程序就连不上。

6.2 版本对照表

  QQ 版本   推荐中间件   实测结果  
 --- --- --- 
  9.9.20 ~ 9.9.29   NapCat 4.18.x   ✅ 可用  
  9.9.30 ~ 9.9.39   NapCat 4.18.x   ❌ 注入失败，QQ 起来就退  
  9.9.30 ~ 9.9.39   SnowLuma 2.2.x   ✅ 可用  
  9.9.40 及以上   未知   需要试，先看工具是否更新  

查自己的 QQ 版本：QQ 左下角菜单 →「关于」；或看 C:\Program Files\Tencent\QQNT\QQ.exe 的属性。

6.3 用 NapCat（适配 QQ 9.9.2x）

① 装工具的两种方式

- 双击目录里的 修复兼容性.cmd，它会检测版本、推荐工具、在你的同意下下载并解压
- 或手动到 github.com/NapNeko/NapCatQQ/releases 下载 NapCat.Shell.zip，解压到 C:\napcat

② 生成 OneBot 配置

修复兼容性.cmd 会自动生成 config\onebot11_<机器人QQ>.json，里面已经写好：

端口 3001 / host 127.0.0.1 / token 空 / messagePostFormat array

手动装的话，把端口改成 3001 即可（其它保持默认）。

③ 启动

1. 确认 QQ 已登录（NapCat 复用现有登录态）
2. 运行 NapCatWinBootMain.exe "D:\qq\QQ.exe" "C:\napcat\NapCatWinBootHook.dll" -q 机器人QQ
3. 等它打印 WebSocket 服务已启动

④ 回本程序

双击「林知夏 测试连接」→ 看到「连接成功」。

【提示】「修复兼容性」会自动做完 ①~③
检测版本 → 下载对应工具 → 解压到 C:\napcat → 生成 OneBot 配置（端口 3001）
→ 问你一句要不要现在启动 → 启动后 QQ 会重启一次，扫码登录即可。
你只需要：扫码 + 回向导点「测试连接」。

6.4 用 SnowLuma（适配 QQ 9.9.3x）

① 装

- 双击 修复兼容性.cmd，它会推荐 SnowLuma 并下载
- 或手动到 github.com/SnowLuma/SnowLuma/releases 下载 lite 版，解压到 C:\snowluma

② 启动

1. 先启动并登录 QQ
2. 运行 C:\snowluma\launcher.bat
3. 浏览器打开 http://127.0.0.1:5099

③ 在 WebUI 里接入

- 扫码或复用现有登录
- 找「OneBot / WebSocket」相关设置，把监听端口设为 3001
- 保存并启用

④ 回本程序

双击「林知夏 测试连接」。

【注意】SnowLuma 的配置在网页里，脚本帮不了
「修复兼容性」会帮你下载、解压、启动，并打开 http://127.0.0.1:5099。
但初始密码只在 SnowLuma 窗口里显示，接入 QQ 和新建 OneBot 连接必须在网页里操作：
登录 → 接入 QQ（扫码）→ 新建 WebSocket 服务，端口填 3001 → 保存启用。

6.5 关掉 QQ 自动更新（必做）

中间件是按 QQ 版本适配的，QQ 一自动升级，原本能用的中间件可能立刻失效。

【重要】这是最容易被忽略、又最容易出事的一步
不关自动更新，某天早上你会发现 QQ 连不上了——不是程序坏了，是 QQ 自己升级了。

QQ 里操作：

左下角菜单 → 设置 → 关于 / 更新 → 选「不自动更新」

部分版本在「设置 → 通用 → 自动更新」里，看到类似开关就关掉。

关掉之后想升级，只能手动去官网下载——这也正是我们想要的：你决定什么时候升级，而不是半夜被升级搞挂。

6.6 版本不匹配怎么办

三种情况，三种处理：

  情况   现象   处理  
 --- --- --- 
  QQ 太新，工具太旧   工具窗口报注入失败，3001 不监听   换匹配的工具（修复兼容性.cmd 会推荐）  
  QQ 太旧，工具太新   同上   换旧版工具，或升级 QQ（有数据风险，见下）  
  都对，但没登录   工具起来了但没连上 QQ   在工具里扫码登录  

为什么本程序不帮你降级 QQ：

- 腾讯不提供旧版本的官方下载入口
- QQ NT 的本地数据库会随版本升级，升级后不保证能降级读回
- 降级属于高风险操作，必须由你本人决定

【严重】改 QQ 版本前，先备份这个目录
不备份就降级，可能读不回本地聊天记录（NT 版数据库升级不可逆）。
我们程序自己的记忆库不受影响，但你的 QQ 聊天记录会。

把整个目录复制到别处（U 盘或其它盘）：
C:\Users\你的用户名\Documents\Tencent Files

并且知道：换版本或换安装路径后，可能需要重新扫码登录。

6.7 白名单机制

只有 .env 里 ALLOWED_QQS 列出的 QQ 号，她才会回复。别人的消息直接忽略。

- 第一个号是"主人"，会收到主动消息
- 加人：后台「访问权限」页，或直接改 app\.env 后重启
【注意】白名单是"允许名单"，不是"拉黑"
清空白名单 = 谁都不回。想让谁都能聊，得把他加进去，而不是留空。



7. 日常使用

7.1 聊天

在 QQ 里正常发消息即可。她会：

- 分条回复（像真人打字）
- 偶尔发表情包
- 记住你说过的事，之后提起

7.2 管理后台

地址：http://127.0.0.1:3870（token 在 app\data\web-token）

主要页面：

  页面   你能改什么  
 --- --- 
  概览   看今天聊了多少、用了多少钱  
  人设   名字、性格、说话风格、口头禅  
  模型   API Key、Base URL、模型名、温度  
  记忆   记多少轮、什么时候总结  
  节奏   打字速度、分条间隔、是否连发  
  主动消息   开关、空闲多久找你、每天最多几条  
  语音   开关、音色（需另配语音服务）  
  安全   内容边界、频率限制、黑名单  

改完即时生效，不用重启（个别项除外）。

7.3 主动消息

默认开：空闲 90 分钟以上，她会主动发一条，每天最多 3 条。

觉得烦：后台「主动消息」关掉，或把 app\.env 里 PROACTIVE 改成 0。

7.4 换一个人设

后台「人设」页可以直接改；也可以放新的 personas\xxx.json，然后在 .env 里把 PERSONA 改成 xxx。



8. 数据与备份

8.1 数据在哪

D:\林知夏\app\data\
  bot.db         聊天记录 + 长期记忆（最重要）
  bot.db-wal     数据库日志（运行时存在）
  web-token      后台访问令牌
  sandbox.db     浏览器测试台的独立记录

8.2 怎么备份

手动备份（推荐每月一次）

1. 双击「停止林知夏」
2. 把整个 app\data 文件夹复制到别处
3. 双击「启动林知夏」

【重要】必须先停止程序
运行中直接复制，可能拿到写到一半的数据库（还有 -wal 文件没合并）。
正确顺序：停止 → 复制 → 启动。

8.3 怎么恢复

1. 停止程序
2. 把备份的 data 文件夹覆盖回 app\data
3. 启动

8.4 换电脑迁移

1. 旧电脑：停止程序 → 复制整个安装文件夹（含 data）
2. 新电脑：放到同版本目录 → 双击 一键安装.cmd 走一遍
3. 安装向导会读已有 .env，Key 和白名单不用重填

注意：换电脑后 QQ 中间件要重新装（跟本程序无关）。

8.5 聊天记录会不会被上传

不会。记录只存在 bot.db。只有生成回复时，最近几轮对话会作为上下文发给模型 API——这是所有大模型应用的必需流程。



9. 故障排查

9.1 QQ 不回复

按顺序查：

  检查项   怎么查   正常表现  
 --- --- --- 
  程序在跑吗   桌面「林知夏 管理后台」能不能打开   能打开  
  中间件在跑吗   浏览器开 http://127.0.0.1:3001 或看工具窗口   工具显示已连接  
  端口通吗   双击「测试连接」   显示「连接成功」  
  白名单对吗   后台「访问权限」   你的号在列表里  
  模型有额度吗   后台「概览」看最近调用   有成功记录  

9.2 常见报错对照

  报错   原因   处理  
 --- --- --- 
  ECONNREFUSED 127.0.0.1:3001   中间件没启动/端口不对   启动中间件；核对 .env 的 ONEBOT_WS_URL  
  401 / 连接被拒   token 不一致   中间件和 .env 里填一样的 token  
  连接成功 但 QQ 不回   白名单没你的号   后台「访问权限」加上  
  回复很慢（>20 秒）   模型服务慢 / 网络差   切模型或换网络  
  insufficient balance   API 余额不足   去模型平台充值  
  invalid api key   Key 填错或过期   后台「模型」页重填  
  后台打不开   程序没启动 / 端口被占   停止再启动；改 .env 的 WEB_PORT  
  中文乱码   用记事本另存过 .env   用后台改，别手动存  

9.3 中间件相关

  现象   原因   处理  
 --- --- --- 
  NapCat 窗口闪退   QQ 版本不匹配   换 SnowLuma 或降 QQ（6.6）  
  工具说"注入失败"   QQ 版本高于工具支持   同上  
  工具起来了，QQ 没登录   需要扫码   在工具里扫码  
  QQ 更新后突然全挂   自动更新没关   关更新（6.5），换匹配版本  

9.4 程序本身

  现象   处理  
 --- --- 
  双击没反应   看 app\logs\app.err.log 最后几行  
  启动后马上退出   检查 app\.env 是否被改坏（可删掉重跑安装）  
  端口冲突   安装会自动换端口；手动改 WEB_PORT  
  磁盘满   数据在 app\data，清理或迁移

13. 卸载与重装

13.1 卸载（双击「卸载.cmd」）

1. 双击目录里的「卸载.cmd」
2. 弹窗告诉你要删什么（程序大小、快捷方式数量、安装目录）
3. 勾选「保留聊天记录」（默认勾着）→ 点「卸载」
4. 几秒后提示「卸载完成」

勾选保留会怎样：把 app\data 复制到桌面（命名 林知夏-聊天记录-年月日-时分），再删掉程序目录。重装后把这些文件放回 app\data 就能恢复。

不勾选：连记录一起删，删了找不回来。

13.2 会删什么、不会删什么

  会删   不会删  
 --- --- 
  程序文件（约 116 MB）   你的 QQ 和 QQ 的聊天记录  
  桌面 5 个快捷方式   系统设置、注册表项  
  app\data（不勾保留时）   其它任何文件  

【注意】有文件被占用删不掉
极少数情况（杀软正在扫描）会删不完全，弹窗会提示重启后手动删除。
重启后把剩下的文件夹删掉即可，不影响系统。

13.3 手动卸载（卸载.cmd 丢了时）

1. 双击「停止林知夏」（或任务管理器结束 node.exe）
2. 删掉桌面 5 个快捷方式
3. 删掉整个安装文件夹

13.4 升级到新版本

卖家发给你一个「升级包」（约 1~3 MB，比整个安装包小很多）。

1. 解压升级包（会得到一个文件夹，里面有 升级.cmd）
2. 把解压出来的东西，复制到「林知夏」安装目录里（覆盖）
3. 双击目录里的「升级.cmd」
4. 它会：停程序 → 备份旧版 → 替换代码 → 启动验证
5. 看到「升级完成，程序已启动」就好了

【重要】升级不会动你的数据
只替换程序代码。app\data（聊天记录）、app\.env（你的配置）、依赖都不会动。

【注意】升级失败会自动回滚
如果新版起不来，它会自动恢复成升级前的版本，并在 backup\ 里留一份备份。
这时候把窗口内容截图发给卖家即可。

13.5 重装

1. 保留 app\data（如果要留记录）
2. 删除其它文件
3. 重新解压安装包，把 data 放回 app\data
4. 双击 一键安装.cmd
