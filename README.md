# 林知夏 · 自托管 AI 陪伴机器人

一个跑在自己电脑上的 AI 陪伴机器人。不是"套壳聊天"——它有一天的生活、会积累情绪、记得你说过的事。

QQ 只是入口，核心是四层结构：

```
感知层   读懂这一句话（语气/强度/意图/话题/他对她做了什么）
场景层   她的一天（时间带、地点、手头的事、可讲的话题）
情绪层   她的情绪（事件注入 → 半衰期衰减 → 影响语气）
记忆层   事实 / 情节 / 摘要，按关键词召回
裁决层   这一轮该接住、先接情绪，还是说点自己的
生成层   拼 prompt，说人话，分条发出来
```

**只有两处调模型**（感知 + 生成），其余全是本地规则，一轮大约 ¥0.004。

## 特点

- **像真人**：4-15 字短句、分条发、打字节奏、会顶嘴也会关心
- **有自己的生活**：早上在煮咖啡、下午在改稿、深夜在厨房找吃的
- **记得住**：你说过的膝盖疼、不吃香菜、在忙的稿子
- **有情绪**：被领导说了会烦躁半天，心情好会主动找你
- **不打扰**：上班时间几乎不主动发消息，睡前才话多

## 快速开始

需要：Windows 10/11、Node.js 20+、一个模型 API Key（DeepSeek 或任意 OpenAI 兼容接口）

```bash
# 1. 装依赖
npm install

# 2. 配置
cp .env.example .env
#   填 DEEPSEEK_API_KEY（或任意兼容接口的 key + base_url）

# 3. 跑起来（不连 QQ，只用浏览器测试台）
node --env-file=.env src/index.mjs
# 浏览器打开 http://127.0.0.1:3871 → 测试台

# 4. 想接 QQ：装 NapCat / SnowLuma，填 ONEBOT_WS_URL 后重启
```

最小可跑只需要一个 Key，语音、表情包、看图都是可选能力。

## 配置

`.env` 里常用的几项：

| 变量 | 说明 |
|---|---|
`DEEPSEEK_API_KEY` | 模型 Key（必填） |
`DEEPSEEK_BASE_URL` | 接口地址，默认 `https://api.deepseek.com` |
`ONEBOT_WS_URL` | OneBot 的 WebSocket 地址（接 QQ 时填） |
`ALLOWED_QQS` | 白名单，只有这些人能跟她说话 |
`WEB_PORT` | 后台端口，默认 3870 |
`PERCEIVE` `ACT_LAYER` `UAFFECT` | 各层开关，出问题可单独关掉退化为旧行为 |

## 后台

浏览器打开 `http://127.0.0.1:3870`：

- **时间线**：她这一天换了几次场景、情绪曲线、聊了几次
- **对话回放**：每一轮的感知、裁决、场景、情绪、花费
- **记忆**：事实 / 情节 / 摘要
- **测试台**：不用 QQ 直接聊，可切换人设

## 目录

```
src/            核心逻辑（感知/场景/情绪/记忆/裁决/生成）
server/         后台 HTTP 接口
web/            后台前端（React + Vite）
personas/       人设 + 生活设定（单文件：人设里写 life）
installer/      Windows 安装向导 / 自检 / 诊断 / 修复 / 升级
scripts/        构建、测试、数据工具
```

## 人设怎么加

一个人设 = 一个 JSON 文件，放在 `personas/`，自带作息和场景：

```json
{
  "name": "小鲸",
  "role": "女朋友",
  "traits": ["贪吃", "嘴硬心软"],
  "speech": "短句，爱用「哼」开头",
  "fewShots": [{ "u": "在干嘛", "a": ["扒饭", "第二碗了"] }],
  "life": {
    "preset": { "wake": 10, "workStart": 11, "workEnd": 19, "sleep": 2 },
    "scenes": [
      { "band": "noon", "place": "home", "location": "家",
        "doing": "在吃白饭",
        "items": [{ "text": "白饭第二碗", "kind": "meal", "expectMin": 20 }] }
    ]
  }
}
```

`fewShots` 是效果最大的一项——模型主要靠示例学"她怎么说话"。
